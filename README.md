# Arsenal Fighting

Адаптивный сайт клуба единоборств в Тольятти. HTML, CSS и JavaScript без сборки и внешних зависимостей во время работы. Шрифты и фотографии хранятся локально.

## Локальный запуск

```sh
python -m http.server 8080
```

Открыть http://localhost:8080. Можно также открыть `index.html` напрямую.

## Публикация

GitHub Actions публикует сайт в GitHub Pages после push в `main`. В Settings → Pages выбрать GitHub Actions.

## Содержимое

- `index.html` — тексты, контакты, ссылки.
- `style.css` — адаптивный дизайн.
- `script.js` — мобильное меню и выбор направления.
- `assets/` — локальные изображения и шрифты.

Основное сообщество, предоставленное заказчиком: https://vk.ru/arsenalfighting. Контакты, направления и клубное фото взяты из https://arsenalfighting.orgs.biz/. Телефон и адрес следует сверить с администрацией перед официальным запуском. Расписание, цены и спортивные регалии не выдуманы и не заявлены. Кнопки записи ведут в сообщество клуба; сайт не собирает персональные данные и не имитирует отправку заявки.
